# EcomWithUsama Backend (NestJS)

This is the NestJS + TypeScript backend for the EcomWithUsama platform.

## Live Demo

Frontend: [https://ecomwithusama.com](https://ecomwithusama.com)

---

## Overview

- **Framework:** NestJS + TypeScript
- **Auth:** Supabase (proxied)
- **Database:** Supabase PostgreSQL (structured), MongoDB (inventory)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run start:dev
   ```

## Project Structure

- `src/` — Main backend source code (modules, controllers, services)
- `docs/` — Documentation and SQL setup
